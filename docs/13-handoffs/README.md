# Handoffs

Handoff tổng hợp hiện tại: `2026-08-24-master-project-handoff.md`.

Handoff là artifact tạm, tên `YYYY-MM-DD-<task>.md`, không phải source of truth. Format bắt buộc:

```text
DONE
VERIFIED
REMAINING
KNOWN ISSUES
RELEVANT FILES
NEXT
```

Khi task kết thúc, chuyển kiến thức còn giá trị về canonical docs và archive handoff cũ ở đợt maintenance kế tiếp.
